
# CoffeeApp

A C# console application developed as a learning project during my 20-week internship at Buss-IT-Labs.

## About the Project

CoffeeApp is a simple coffee ordering system that allows users to select drinks, manage orders, and calculate the total price.

## Features

- Display a menu of available drinks
- Add drinks to an order
- Review the current order
- Calculate the total price
- Navigate through a console-based menu

## Technologies

- C#
- .NET 10
- Console Application
- Object-Oriented Programming

## Getting Started

### Requirements

- .NET 10 SDK
- Visual Studio or another compatible IDE

### Run the Application

Open the solution in Visual Studio and start the project.

Alternatively, navigate to the directory containing the `.csproj` file and run:

```bash
dotnet run
```
